# test-public

A disposable repository for testing GitHub behaviour: issues, labels, pull requests, Actions runs, auto-merge and merge queues.

Everything here is throwaway. Issues, pull requests, branches and runs may be created, changed or deleted at any time without notice. Do not keep anything here that you want to keep.

This repository is not part of the fleet: no agent draws work from it. It is used only as a target by tests run elsewhere.
